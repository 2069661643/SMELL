# Ailog 260927-121756 — SMELL-v3: TC 完成 —— fp32 下 cos 与理论吻合，ZOO 路线打通

## 概述

TC（fp32、SDPA、16k、layer0、30 client）完成：**`cos ≈ 0.5·√(cLD/d_eff)`，与理论同标度**（bf16 时 ratio 仅 0.01–0.08）。**bf16 损失量化确为唯一根因；fp32 下 ZOO 梯度恢复**。但 **fp32 前向 ~2.9s（bf16 ~0.33s，9×）**，使 ZOO 单轮成本显著，TD 需做成本权衡。

- **cos 随 `c/L/D` 按 √(cLD/d) 增长**；ratio 稳定 ≈ **0.5**（小 M 时 ~1.0）。
- 对照 bf16（同网格）：ratio 0.01–0.08、cos ≤0.032 ⇒ **fp32 把 cos 从 ~0 提到理论量级**。
- 达 **cos≥0.15**：`L=2,D=32,c=10`（0.149）或 `c≥20`；或 `L=1,D=32,c=30`（0.165）。

## 成本（fp32 前向 2.89s）

ZOO 每轮前向 = `c·L·(1+2D)`：
| 配置 | 前向/轮 | 每轮 | cos |
|---|---|---|---|
| c30 L1 D8 | 510 | ~25 min | 0.093 |
| c30 L2 D8 | 1020 | ~49 min | 0.120 |
| c30 L1 D32 | 1950 | ~1.6 h | 0.165 |
| c30 L2 D32 | 3900 | ~3.1 h | 0.242 |
| c10 L2 D32 | 1300 | ~1.0 h | 0.149 |

⇒ 达 cos≈0.15 需 **~1–1.6 h/轮**；30 轮 ~30–50h。**成本是 TD 的主要约束。**
