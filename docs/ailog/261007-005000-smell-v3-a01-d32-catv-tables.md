## 四、结论

1. **CATV 的收益强 α 依赖**：α=0.3（a03）训练上全指标显著正收益（full −0.6%、answer −16.9%，配对 p≈0）；α=0.1（a01）训练效应**不显著**（full p=0.975、answer p=0.10），部署口径的小幅 answer 收益（−3.0%）主要来自**评测掩码本身**（−2.1~6.4%）。
2. 评测掩码是所有 CATV 数字的共同成分：full +0.23~0.40 的代价、answer 小幅收益；跨 tag 量级一致。
3. 无 CATV 基线：a01 与 a03 几乎同级（full 31.467 vs 31.410；answer 2907 vs 2871）⇒ α 对基线影响小，**差异集中在 CATV 的交互项**。
4. 候选机制：α=0.1 客户端分布更异质 → 共识锚与任务 token 的相关性变弱（IR 同为 ~0.92，IR 不足以预警）。→ 论文里 CATV 应配合 α 消融报告，或做 α×r 交互扫描。
