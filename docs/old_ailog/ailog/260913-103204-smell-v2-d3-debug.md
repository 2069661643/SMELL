# SMELL Phase 5 — D3 lm_head LoRA 无效排查 + debug 埋点 + 快轮诊断

## 概述

D3（只训 lm_head LoRA，r=4，samples=1/epochs=1024）跑 11 轮（~14.7h）后，发现 **PPL 逐位等于 baseline（45.0380）**，即客户端 loss 无任何变化，怀疑 server→client 参数同步未真正生效。实现 debug 埋点并改快轮（epochs=16, comm_round=201）快速定位。

## D3 现象（异常）

| 项 | 值 |
|---|---|
| 运行 | 19:21:47 → 10:05:09，**~14.7h，11 轮** |
| `[EVAL-PPL]` | baseline=45.0380，round 0–10 **全部 45.0380 / eval_loss 3.8075（逐位相同）** |
| resample | 0（M=3072） |

**验证**：
- Server checkpoint r1/r2/r11 参数确有变化（`lora_A` max|Δ|~2.3e-4，`lora_B` max|Δ|~2.8e-4）。
- D3 名称翻译 + `set_model_params` 隔离测试通过（keys 正确、参数被改写）。
- 客户端收到 11 次 model 更新消息。

**矛盾**：server 参数变了 ~2.8e-4，若客户端同样被更新，loss 应可见变化；但 evalloss 逐位不变 → 怀疑真实消息路径下 client 未吃到更新（如 `isinstance(dict)` 未命中导致 `load_state_dict` 静默忽略，或 translation 在运行路径失效）。
