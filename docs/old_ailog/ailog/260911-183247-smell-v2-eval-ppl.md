# SMELL-v2-debug — 每轮固定测试集 eval PPL（--eval_ppl / --eval_seed）

## 概述

长跑 `a0.1_sample10_len4k_datagoe`（sparse 0.4 / c3 / alpha 0.1 / len 4k / samples 10 / max_resample 200）跑到 round 14 时，发现 PPL 日志有三处缺陷：

1. 训练侧 `[SMOKE-PPL]` 基于**随机 30 训练样本**，每轮样本不同 → 跨轮不可比；
2. MORE_V 重采样导致每轮**重复打印多次**（首个=整轮 token 加权，后续=3 样本噪声）；
3. 每 batch 的 `num_valid` 未打印，无法从 loss 精确复现 PPL。

结论：`loss` 是扰动权重均值 `(L(θ+hv)+L(θ−hv))/2`（`fwdgrad_utils.py:213`），非真实 L(θ)；且整轮 PPL 是 token 加权（短样本 loss 高/token 少被降权），与简单 `exp(mean(loss))` 差异 ~0.1–0.47 nats。

本次新增 **Client 端每轮固定测试集 eval**（确定性、跨轮可比），并注释掉训练侧 PPL 打印。

## 设计决策

- 只做层 1（固定测试集 eval），eval 模型**原样**（llama_sparse，含 token elimination + 当前共识 mask）。
- eval 采样 `--eval_ppl` 条（默认 50）、固定 `--eval_seed`（默认 42）保证跨轮可比。
- 不加训练前 baseline eval。
- 训练侧 `[SMOKE-PPL]` 先注释（保留回退能力）。
