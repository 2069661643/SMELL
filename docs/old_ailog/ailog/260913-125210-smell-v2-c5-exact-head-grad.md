# SMELL-v2-debug — C5 对照：瓶颈锁定为 ZOO 估计器 SNR（非聚合/参数化）

## 概述

新增测试脚本 `FwdLLM/.../run_lm_exps/test_exact_head_grad.py`（【测试/诊断脚本，非训练流水线】），在 D3（lm_head-only LoRA, r=4, d=144,384）上取**精确梯度**作为标尺，判定瓶颈在 ZOO 前向梯度估计器还是在聚合/参数化。

## 方法

1. **精确梯度**：截获 `lm_head` 输入 `h`（no_grad 前向）→ **只对 head 重新前向 + 反传**得到 ∂L/∂A,∂L/∂B。
   backbone 冻结 ⇒ 无需穿过 32 层、不保存骨架激活，图极小。与「整模型 `loss.backward()`」互为校验。
2. **JVP 校验**：`<g, v>` 应 ≈ `(L(θ+hv)−L(θ−hv))/(2h)`（h=0.01，与训练同口径）。
3. **ZOO 方向质量**：`grad_M = (1/M)Σ<g,v_i>v_i`，与理论 `√(M/d)` 对照。
4. **精确下降**：用精确梯度做短程 AdamW，看 loss 是否下降。

## 结果（GPU1，sample_index=0，n_valid=27）

| 项 | 值 |
|---|---|
| `\|g_head\|` / `\|g_full\|` | 0.8071 / 0.8071 |
| `cos(head, full)` | **1.000000**（head-only 反传 == 全反传） |
| JVP 校验 | fd=0.847 vs `<g_head,v>`=1.067，rel_err=0.206（FD+bf16 正常） |
| ZOO cos（实测 vs 理论 √(M/d)） | M=10: 0.0069/0.0083；100: 0.0266/0.0263；1000: 0.0839/0.0832；10000: 0.2565/0.2632 |
| 精确下降 loss | 3.4642 → **0.1034**（20 步，lr=0.01, 4 样本） |

解析式 `g_ana`（Σ(p−e)⊗h 再投影 A/B）与真值差 ~570×、cos≈0.002 → **该解析实现未复现**（疑与 peft LoRA 前向/tied-embedding 细节有关），故精确基准改用 head-only 反传；原理（只需最后 hidden+logits）仍成立但闭式实现待查。

## 结论

1. **正确梯度能学**：head-only 精确梯度 20 步把 loss 从 3.46 降到 0.10 → **参数化（lm_head LoRA）与损失口径没有问题**。
2. **瓶颈是 ZOO 估计器方向质量**：单步 cos ≈ 1/√d；平均 M 个样本 ≈ √(M/d)。当前训练 M=clients×epochs：D3 诊断 M=48 → cos≈0.018；高 epoch M=3072 → cos≈0.146。要达到 cos=0.5 需 M≈0.25·d≈**36,000 样本/次更新**（每次 2 次 7B 前向），不可行。
3. 与 A2（更新=随机游走）、A1（PPL 低杠杆）一致：**降 d 能提高 √(M/d) 但仍远不够**；根本出路在改进估计器（结构化/低秩扰动、exact-JVP、或 head-only 解析/局部梯度），而非聚合步长。

## 补充：rank=1 head-only BP 的 PPL 下降可行性（PPL 验证 run）

配置：r=1（d=36,096），head-only BP 在 **train** split 128 样本上 AdamW **lr=1e-3**，40 步；**h 缓存于 CPU**（backbone 冻结 ⇒ h 与 A/B 无关，每样本只跑一次 7B 前向；显存不足故存 CPU）；**test** split 50 样本追踪 PPL。

| step | train_loss | test PPL |
|---|---|---|
| 0 | 4.195363 | 36.741016 |
| 10 | 4.033865 | 37.089439 |
| 20 | 3.699890 | 49.152638 |
| 30 | 3.507595 | 68.576909 |
| 40 | 3.421267 | 82.042456 |

**结论：rank=1 head-only BP 能降训练 loss（4.195→3.421），但 test PPL 单调上升（36.74→82.04，Δ=+45.3）→ 该设置下 PPL 下降不可行（过拟合/发散）。** 梯度本身无误（head==full，cos=1.0），问题在 lr 过大 + 样本过少（d=36k × 128 样本即可扭曲 head）。需更低 lr（1e-4/1e-5）+ 更多样本 + 正则/早停再验证。

另：先前 r=1、lr=0.01、16 样本短跑在 step16 即 PPL 36.7→860，同向更强。
