# 任务概述

本次任务围绕内存峰值测试展开，你需要为Jenga项目测试其在Llama-2-7B-hf模型下微调所用的内存峰值进行测试。本次你不需要运行实际测试，因为模型目前是缺失的，但你要写好RUNME脚本，对部分代码进行适量修改。

- 本次测试分为两个阶段
    - 先是测试内存峰值，如同Jenga中所做的一样，4次输出log文件
        - 稳健性：若OOM就在log内print OOM
    - 第二阶段绘图, 柱状图
        - 横轴上下文长度（英文）1k, 2k, 4k, 8k, 16k
        - 纵轴内存峰（英文），GB
        - 如果OOM就记为0GB
- 架构设计
    - 你需要在/JengaForMemoryTest下做设计
    - 在/JengaForMemoryTest/script放置.sh脚本
    - 在/JengaForMemoryTest/output_figure放置输出图片
    - 在/JengaForMemoryTest/log放置中间log文本
    - 在/JengaForMemoryTest/src放置py文件
- 上下文长度1k, 2k, 4k, 8k, 16k
- 本次仅允许静态检查，不允许实际测试
- 对于每次的修改/创建/删除/执行你需要在/docs/ailog以yymmdd-hhmmss-<任务概述>.md的形式保留你的修改/创建/删除/执行大纲
- /JengaForMemoryTest/Jenga是我复制过来的Jenga文件，与/Jenga一致，你应该使用/修改/JengaForMemoryTest/Jenga
- 你可以尝试使用/JengaForMemoryTest/Jenga下的脚本，但我推荐你自己写一个重定向脚本于/JengaForMemoryTest/script
- 除了可能要插入必要的print以外尽量不要动Jenga代码，如果可以你甚至不要插入（直接运用memory_profile.py）。
